# OpenSim Wrist Biomechanics — ARMS Wrist–Hand Model

Computational analysis of wrist flexion, extension, radial deviation and ulnar deviation with the ARMS Lab hand–wrist model
(`Hand_Wrist_Model_for_development.osim`, OpenSim 4.3 file format). Main deliverable: `08_Report/Final_Report.docx` (+ `.pdf`).

> **All motions and external loads are synthetic.** No experimental motion, force, EMG or imaging data were used. Comparisons with the
> literature are plausibility checks, not experimental validation. Analyses were run in **OpenSim 4.6** (Python API); the model was also
> loaded in **OpenSim 4.4.1**; it has **not** been run in OpenSim 4.3 (see `docs/COMPATIBILITY.md`).

## Layout
| Folder | Content |
|---|---|
| `original_model/` | Unmodified ARMS model (read-only) + `SHA256.txt` |
| `working_model/` | `ARMS_wrist_working.osim` (21 coordinates locked + 2 reserve actuators; text edits only, 4.3 format kept) |
| `opensim_files/` | `.mot` motions, external-load XML/`.mot`, Static Optimization (`results_SO`), Inverse Dynamics (`results_ID`), OpenSim JointReaction (`results_JRA`, *not used for results – see report 13.1*), sensitivity outputs |
| `results/csv`, `results/tables` | Every number in the report is traceable to these files |
| `results/figures` | 30 PNG figures (per movement, comparative, forward dynamics, sensitivity, validation) |
| `results/compat` | OpenSim 4.4.1 vs 4.6 load/moment-arm comparison |
| `scripts/` | All analysis scripts (below) and `build_report.js` |
| `08_Report/` | `Final_Report.docx`, `Final_Report.pdf` |
| `docs/` | Assumptions, compatibility, completed vs incomplete |

## Requirements
Python ≥ 3.9, `opensim` (4.4–4.6 via `pip install opensim` or conda `-c opensim-org`), numpy, pandas, matplotlib, scipy, pillow; Node.js + `docx` (report only).
OpenSim 4.3 can be used for the model checks (`compat_check.py`); the scripts were developed against the 4.6 Python API (small API differences may require edits).

## Execution order (run from `scripts/`)
```
python 01_inspect_model.py              # model tables (bodies, joints, coordinates, constraints, muscles, passive elements)
python 02_conventions_and_momentarms.py # sign-convention test, moment-arm sweeps, finite-difference verification
python 03_kinematics.py ; python 04_plot_kinematics.py
python 05_passive_properties.py ; python 06_plot_muscles.py
python 07_make_working_model.py         # creates working_model/ARMS_wrist_working.osim
python 08_id_so.py                      # writes dyn_* motions, external loads, runs Inverse Dynamics (all combinations)
python 09_verify_id.py                  # ID vs virtual-work statics
bash run_all_so.sh                      # 6 Static Optimization runs (~1 min each); or: python 10_run_so.py <kin> <load>
python 11_verify_so.py                  # convergence / balance checks
python 12_jra.py dyn_flexext Lflex10N_dorsal ; python 13_jra_check.py ; python 14_jra_force_balance.py   # OpenSim JointReaction + checks
python 15_reactions.py ; python 16_jra_compare.py                         # Newton-Euler reactions (reported) + comparison
python 17_tune_fd_baseline.py           # equilibrium baseline for forward dynamics
python 18_forward_dynamics.py           # 5 cases (~25 s each) ; python 19_fd_check.py <case> for each case
python 20_fd_reactions.py baseline,flexion,extension,radial,ulnar
python 21_sensitivity.py so ; python 21_sensitivity.py so_post ; python 21_sensitivity.py fd ; python 21_sensitivity.py num
python 22_plots.py ; python 23_validation.py ; python 24_summary_tables.py ; python 25_report_data.py
node build_report.js                    # DOCX; convert to PDF with LibreOffice
```
Notes: run `19_fd_check.py` in a fresh process per case (the ID tool can crash if reused repeatedly in one process). `21_sensitivity.py so`
accepts a comma-separated variant list; variant models are regenerated by the script. Total runtime ≈ 40 min on one CPU.

## Environment used
OpenSim 4.6 (Python 3.12) for all results; OpenSim 4.4.1 (Python 3.9) for `compat_check.py`; Ubuntu 24 container.
